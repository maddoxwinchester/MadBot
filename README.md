# MadBot Extensions

Portfolio homepage for Maddox's Chrome extensions, hosted on GitHub Pages.
Static site — no backend, no payment processing here. Every "Get it" link
points out to the product's Gumroad page.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any
static file server.

## Deploy

GitHub Pages, served from this repo. Enable under Settings → Pages once
pushed.
